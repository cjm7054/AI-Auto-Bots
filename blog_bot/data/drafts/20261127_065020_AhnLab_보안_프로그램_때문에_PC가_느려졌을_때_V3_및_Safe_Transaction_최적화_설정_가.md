# AhnLab 보안 프로그램 때문에 PC가 느려졌을 때? V3 및 Safe Transaction 최적화 설정 가이드

웹서핑을 하거나 은행, 공공기관 사이트에 접속한 뒤 PC 속도가 갑자기 느려지거나 CPU 점유율이 100%까지 치솟는 현상을 겪어보신 적 있으신가요? 

국내에서 가장 흔히 사용되는 백신 및 보안 솔루션인 **안랩(AhnLab)의 V3 Lite 및 AhnLab Safe Transaction**은 강력한 보안 기능을 제공하지만, 백그라운드에서 과도한 시스템 자원을 소비하여 작업 생산성을 떨어뜨리는 주요 원인이 되기도 합니다.

특히 그래픽 작업, 코딩, 고사양 게임 등을 실행할 때 보안 프로그램과의 충돌로 인한 프레임 드랍이나 렉(Lag) 현상은 많은 사용자들을 불편하게 만듭니다.

본 가이드에서는 **보안 안전성을 유지하면서도 AhnLab 관련 프로그램으로 인한 PC 속도 저하 현상을 완벽하게 해결하는 단계별 최적화 튜토리얼**을 상세히 정리해 드립니다.

---

## 1단계: 원인 분석 및 사전 준비

AhnLab 보안 솔루션이 컴퓨터를 느리게 만드는 원인은 크게 세 가지입니다.

1. **AhnLab Safe Transaction(ASTx)의 상시 백그라운드 실행**: 금융/공공 사이트 접속 시 설치되는 이 프로그램은 사이트를 종료한 후에도 서비스 프로세스에 상주하며 CPU와 메모리를 계속 점유합니다.
2. **V3 실시간 감시의과도한 파일 검사**: 대용량 파일 복사, 코드 빌드, 영상 렌더링 시 실시간으로 모든 파일을 스캔하면서 Disk I/O(입출력) 병목 현상을 일으킵니다.
3. **ASD(AhnLab Smart Defense) 클라우드 진단 연동**: 실시간으로 네트워크를 통해 파일 평판을 조회하는 과정에서 네트워크 지연 및 자원 소모가 발생합니다.

### 💡 [사전 준비] 시스템 자원 점유율 확인하기

먼저 현재 내 PC에서 AhnLab 프로세스가 자원을 얼마나 사용하고 있는지 확인합니다.

1. 단축키 `Ctrl + Shift + Esc`를 눌러 **작업 관리자**를 실행합니다.
2. 상단 검색창에 `AhnLab` 또는 `V3`를 입력합니다.
3. **CPU** 및 **메모리** 점유율을 확인합니다.

[캡처 화면 설명: 작업 관리자 앱의 '프로세스' 탭에서 'AhnLab Safe Transaction Service' 및 'V3 Lite' 항목이 CPU 자원을 10~30% 이상 점유하고 있는 화면]

## 2단계: 단계별 AhnLab 최적화 및 렉 방지 설정

위 문제를 해결하기 위해 시스템 설정을 순서대로 변경해 보겠습니다.

### Step 1. AhnLab Safe Transaction 자동 실행 차단하기

매번 삭제할 필요 없이, 금융 사이트를 이용할 때만 작동하고 평소에는 멈추도록 설정할 수 있습니다.

1. 단축키 `Win + R`을 눌러 실행 창을 엽니다.
2. `services.msc`를 입력하고 `Enter`를 누릅니다.
3. 서비스 목록에서 **`AhnLab Safe Transaction Service`** 항목을 찾습니다.
4. 해당 항목을 마우스 우클릭한 후 **[속성]**을 클릭합니다.
5. **[일반]** 탭의 **시작 유형(E)**을 `자동`에서 **`수동`**으로 변경합니다.
6. 아래의 **[중지]** 버튼을 눌러 현재 실행 중인 서비스를 멈춘 후 **[확인]**을 누릅니다.

[캡처 화면 설명: 서비스 관리자 창에서 AhnLab Safe Transaction Service 속성 창을 열고, 시작 유형 드롭다운 메뉴에서 '수동'을 선택하는 화면]

> 📌 **주의**: '수동'으로 설정해 두면 은행 사이트 접속 시 필요할 때만 자동으로 실행되며, 웹서핑 종료 후 불필요하게 자원을 먹는 현상이 사라집니다.

---

### Step 2. V3 Lite CPU 점유율 제어 및 검사 예외 설정

V3 백신이 실시간으로 시스템 자원을 탐식하지 않도록 환경 설정을 변경합니다.

1. 작업 표시줄 우측 하단 트레이 아이콘에서 **V3 Lite**를 더블 클릭하여 실행합니다.
2. 메인 화면 좌측 하단의 **⚙️ [환경 설정]** 아이콘을 클릭합니다.
3. **[PC 검사 설정] > [PC 미사용 시 검사]** 옵션을 **'체크 해제'**합니다.
4. **[검사 예외 설정]** 메뉴로 이동합니다.
5. **[폴더 추가]**를 클릭하여 개발용 프로젝트 폴더, 영상 편집 작업 폴더, 게임 설치 경로 등 자주 사용하는 작업 디렉터리를 예외 목록에 등록합니다.

[캡처 화면 설명: V3 Lite 환경 설정 내 '검사 예외 설정' 메뉴에서 특정 작업 폴더 경로를 추가하여 실시간 감시 대상에서 제외하는 설정 화면]

---

### Step 3. 알림 팝업 및 스마트 진단(ASD) 최적화

불필요한 알림창과 백그라운드 통신을 줄여 쾌적한 환경을 만듭니다.

1. V3 환경 설정 메뉴에서 **[기타 설정] > [알림 설정]**으로 이동합니다.
2. **'보안 상태 알림 팝업 창 표시'** 및 **'쇼핑/광고 알림 팝업'** 항목을 모두 **'체크 해제'**합니다.
3. **[Active Defense 설정]**으로 이동하여 클라우드 평판 조회 수준을 `보통`에서 **`낮음`** 또는 **`사용 안 함`**으로 조정합니다. (단, 출처가 불분명한 파일을 자주 다운로드하는 환경이라면 `보통` 유지를 권장합니다.)

## 3단계: 실무 활용 꿀팁 및 옵션 비교표

AhnLab 프로그램을 무작정 삭제하는 것보다 환경에 맞춰 옵션을 다듬는 것이 보안과 성능의 균형을 맞추는 최선의 방법입니다. 아래 비교표를 참고하여 본인의 PC 사용 패턴에 맞게 설정하세요.

### 📊 AhnLab 설정 항목별 성능 최적화 비교표

| 설정 항목 | 기본 설정값 | 권장 최적화 설정 | 설정 후 기대 효과 |
| :--- | :--- | :--- | :--- |
| **Safe Transaction 시작 유형** | 자동 (상시 실행) | **수동** | 부팅 속도 향상, 메모리 300MB~500MB 확보 |
| **V3 실시간 감시 대상** | 모든 파일 및 프로세스 | **작업/게임 폴더 예외 추가** | 대용량 작업 시 파일 읽기/쓰기 렉 완벽 제거 |
| **PC 미사용 시 자동 검사** | 켜짐 | **꺼짐** | 잠시 자리를 비웠을 때 팬 소음 및 CPU 과열 방지 |
| **ASD 클라우드 연동** | 높음/보통 | **보통 또는 끄기** | 인터넷 패킷 지연(Ping) 감소 및 백그라운드 네트워크 대역폭 확보 |
| **광고 및 상태 알림 팝업** | 켜짐 | **모두 끄기** | 꽉 찬 화면(게임, 발표) 중 튕김 현상 예방 |

## 4단계: 자주 발생하는 오류 및 트러블슈팅 FAQ

컴퓨터 환경에 따라 설정 적용 중 문제가 발생할 수 있습니다. 가장 문의가 많은 3가지 사례와 해결 대책입니다.

### Q1. Safe Transaction 서비스 시작 유형을 '수동'으로 바꿨는데 PC를 재부팅하면 다시 '자동'으로 돌아갑니다.
> **해답**: 일부 은행 보안 모듈(Kookmin, Shinhan 등)이 웹사이트 접속 시 자체 서비스 제어권을 행사하여 설정을 다시 '자동'으로 되돌리는 경우가 있습니다. 이 경우, `제어판 > 프로그램 및 기능`에서 사용하지 않는 금융 보안 프로그램들을 일괄 삭제하거나, **'구글 크롬 확장 프로그램'** 형태로 제공되는 가상 키보드 방식을 사용하는 것이 가장 깔끔합니다.

### Q2. V3 실시간 감시 예외 설정을 해두면 바이러스 감염 위험이 커지지 않나요?
> **해답**: Steam, Epic Games 등의 정식 게임 폴더나 본인이 직접 작성하는 코딩/영상 프로젝트 폴더처럼 **안전성이 검증된 경로만 지정**한다면 보안 위험성은 거의 없습니다. 신뢰할 수 없는 다운로드 폴더(`C:\Users\사용자\Downloads`) 등은 절대 예외 등록을 하지 마세요.

### Q3. 작업을 모두 마쳤는데도 `StSess.exe` 프로세스가 계속 메모리를 차지하고 있습니다.
> **해답**: `StSess.exe`는 Safe Transaction의 핵심 실행 파일입니다. 서비스 종료 후에도 메모리에 잔재가 남은 경우, 명령 프롬프트(`cmd`)를 **관리자 권한**으로 실행한 후 아래 명령어를 입력하여 즉시 종료시킬 수 있습니다.
> ```bash
> taskkill /f /im StSess.exe
> ```

AhnLab 보안 프로그램은 한국 인터넷 환경에서 필수적이지만, 과도한 설정은 PC 성능의 발목을 잡습니다. 안내해 드린 단계별 가이드를 통해 최적화를 완료하면 보안성을 유지하면서도 훨씬 쾌적하고 빠른 PC 환경을 체감하실 수 있습니다.
