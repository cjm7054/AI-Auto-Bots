# 실리콘밸리 로봇격투 기술의 핵심: Isaac Sim 기반 휴머노이드 물리 시뮬레이션 환경 구축 가이드

최근 실리콘밸리에서는 단순한 이동이나 물건 운반을 넘어, 칼을 휘두르고 날아차기를 하는 고난도 휴머노이드 로봇 격투 및 격렬한 운동 제어 기술이 큰 화제를 모으고 있습니다. 

이러한 로봇들의 역동적인 움직임은 사람이 일일이 동작을 코딩한 것이 아닙니다. **수만 번의 실패를 가상 공간에서 반복하며 스스로 학습하는 '강화학습(Reinforcement Learning)'과 '물리 시뮬레이션' 기술**이 결합된 결과입니다.

실제 로봇을 가지고 이런 고난도 동작을 테스트하면 로봇이 파손되어 수천만 원의 비용이 발생합니다. 따라서 실리콘밸리의 테크 기업과 로봇 공학자들은 **NVIDIA Isaac Sim**이나 **MuJoCo** 같은 고성능 3D 물리 시뮬레이터 내에서 로봇을 마구 굴리며 학습시킵니다. 

이번 가이드에서는 로봇 공학 분야에 입문하거나 AI 기반 모션 제어를 연구하려는 분들을 위해, **실리콘밸리 스타트업들이 사용하는 방식을 그대로 따라 내 PC에 휴머노이드 강화학습 시뮬레이션 환경을 100% 구축하는 단계별 절차**를 명확하게 정리해 드립니다.

## 1단계: 필수 사전 준비 사항 및 시스템 사양 체크

고속의 물리 연산과 디스플레이 렌더링을 동시에 처리해야 하므로 일반적인 사무용 PC에서는 시뮬레이터 구동이 어려울 수 있습니다. 설치 전 최신 개발 환경 기준 사양을 반드시 확인하세요.

### 📜 최소 및 권장 시스템 사양 (2026년 기준)

- **OS**: Windows 11 (22H2 이상) 또는 Ubuntu 22.04 / 24.04 LTS
- **GPU**: NVIDIA GeForce RTX 3080 이상 (VRAM 12GB 이상 필수, RTX 4080/5080 권장)
- **CPU**: Intel Core i7 13세대 이상 또는 AMD Ryzen 7 7000 시리즈 이상
- **RAM**: 32GB 이상 (64GB 권장)
- **드라이버**: NVIDIA Display Driver 550.x 이상 (CUDA 12.x 지원 버전)

### 🛠️ 사전 설치 필요 프로그램
1. **Python 3.10 이상**: 물리 엔진과 강화학습 라이브러리 연동용
2. **Anaconda / Miniconda**: 독립된 가상환경 관리를 위해 필수
3. **Git**: 최신 로봇 RL(강화학습) 리포지토리 클론용

## 2단계: 핵심 단계별 환경 구축 절차 (Step-by-Step)

### Step 1: NVIDIA Omniverse 및 Isaac Sim 설치하기

NVIDIA Isaac Sim은 파티클 기반 물리 연산과 병렬 GPU 컴퓨팅을 활용해 로봇의 격투, 동적 도약 동작 등을 실시간에 가깝게 시뮬레이션해 주는 최강의 도구입니다.

1. **NVIDIA Omniverse Launcher 다운로드**: NVIDIA 공식 개발자 사이트에 접속하여 `Omniverse Launcher` 설치 파일을 다운로드합니다.
2. **실행 및 로그인**: 설치 완료 후 앱을 실행하고 NVIDIA 계정으로 로그인합니다.
3. **Isaac Sim 앱 설치**:
   - 상단 메뉴에서 `EXCHANGE` 탭을 클릭합니다.
   - 검색창에 **Isaac Sim**을 입력합니다.
   - 최신 안정화 버전(Isaac Sim 4.x 이상)을 선택하고 `INSTALL` 버튼을 누릅니다.

[캡처 화면 설명: Omniverse Launcher 실행 후 'EXCHANGE' 탭에서 Isaac Sim 카드를 클릭하여 오른쪽 상단의 붉은색/초록색 Install 버튼을 활성화한 화면]

---

### Step 2: Python 가상환경 구성 및 CUDA 연동

시뮬레이터와 강화학습 프레임워크(PyTorch) 간 라이브러리 충돌을 방지하기 위해 독립된 Anaconda 가상환경을 생성합니다.

1. `Win + R` 키를 누르고 `cmd`를 입력하여 단축키로 명령 프롬프트를 열거나 Terminal을 실행합니다.
2. 아래 명령어를 순서대로 입력하여 가상환경을 생성하고 활성화합니다.

```bash
# 1. conda 가상환경 생성 (Python 3.10 지정)
conda create -n isaac_robot python=3.10 -y

# 2. 가상환경 활성화
conda activate isaac_robot

# 3. PyTorch 및 CUDA 12.x 토치 패키지 설치
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

---

### Step 3: 휴머노이드 로봇 RL 템플릿(Omniverse Isaac Gym) 클론 및 설정

실리콘밸리 연구진이 공개한 로봇 격투 및 아크로바틱 제어 프레임워크 기반 라이브러리를 가져옵니다.

1. 원하는 작업 디렉토리로 이동한 뒤 Git 명령어로 리포지토리를 클론합니다.

```bash
cd C:\workspace
git clone https://github.com/isaac-sim/IsaacLab.git
cd IsaacLab
```

2. 종속성 라이브러리를 현재 활성화된 Conda 환경에 설치합니다.

```bash
python -m pip install -e .
```

[캡처 화면 설명: 터미널 창에서 `pip install -e .` 명령어가 실행되며 `isaaclab` 관련 파이썬 패키지들이 버그 없이 Successfully installed 문구로 마감되는 화면]

---

### Step 4: 휴머노이드 격투/보행 학습 스크립트 첫 실행

설치가 완료되었으면, 기본 탑재된 휴머노이드(Humanoid) 로봇이 물리 법칙에 따라 일어서고 균형을 잡는 학습 파이프라인을 구동합니다.

1. Terminal에서 아래 실행 명령어를 입력합니다.

```bash
python scripts/reinforcement_learning/rllib/train.py --task Isaac-Velocity-Humanoid-v0 --headless False
```

2. 몇 초 후 **Isaac Sim 3D 뷰포트 창**이 팝업되면서 1,000대 이상의 로봇이 동시에 격자 형태로 배치되어 넘어지고 다시 일어서며 학습을 시작하는 장관이 연출됩니다.

## 3단계: 실무 활용 꿀팁 및 시뮬레이터 물리 파라미터 비교표

로봇이 격투 동작이나 날아차기 같은 격렬한 동작을 할 때 시뮬레이션 내 로봇 관절이 비정상적으로 비틀리거나, 가상에서 잘 되던 동작이 실제 로봇으로 이전 시 무너지는 **Sim-to-Real Gap** 현상이 발생합니다. 이를 방지하기 위한 핵심 물리 설정 옵션을 비교 정리해 드립니다.

### 📊 물리 시뮬레이션 엔진 최적화 파라미터 비교표

| 설정 항목 (Physics Parameter) | 기본값 (Default) | 권장 최적값 (RL 격투/동적 동작용) | 설정 효과 및 권장 이유 |
| :--- | :--- | :--- | :--- |
| **Physics Time Step (dt)** | `1/60s (0.0166)` | **`1/200s (0.005)`** | 타격 및 고속 도약 시 프레임 스킵으로 인한 관절 뚫림 현상 예방 |
| **Solver Substeps** | `4` | **`8 ~ 12`** | 관절 임팩트 시 수치적 불안정성(Explosion) 방지 및 관절 찢어짐 억제 |
| **Friction Randomization** | Disabled | **`Enabled (0.4 ~ 1.2)`** | 실제 지면 바닥 재질(고무, 목재, 링 등) 마찰력 변수에 견디는 제어력 확보 |
| **Joint Damping (관절 감쇠)** | `0.0` | **`5.0 ~ 20.0`** | 모터 제어 신호 급변 시 발생하는 고주파 진동(Jittering) 현상 차단 |

### 💡 실무 생산성 극대화 꿀팁 (Tip)
- **Headless 모드 활용**: 로봇 자세 학습 초기(초기 5,000 에포크)에는 화면 렌더링을 끄는 `--headless` 옵션을 추가하세요. 학습 속도가 최소 **3배 이상 증가**합니다.
- **Domain Randomization(영역 무작위화) 필수 적용**: 로봇의 질량, 모터 렌더링 지연(Latency), 바닥 마찰력을 매 에피소드마다 5~10%씩 랜덤으로 바꾸어 학습시켜야 실제 로봇에 탑재했을 때 넘어지지 않습니다.

## 4단계: 자주 발생하는 오류 및 트러블슈팅 FAQ

### Q1. `CUDA out of memory` 에러가 발생하면서 시뮬레이터가 강제 종료됩니다.
**원인**: 한 번에 시뮬레이션하는 로봇 개수(`num_envs`)가 GPU의 VRAM 용량을 초과했기 때문입니다.  
**해결 방법**:
학습 실행 파라미터 중 환경 개수를 줄여서 입력하세요.
```bash
# 기본 num_envs=4096에서 1024 또는 512로 줄여서 실행
python train.py --task Isaac-Velocity-Humanoid-v0 --num_envs 1024
```

---

### Q2. 로봇이 학습을 시작하자마자 하늘로 튕겨 날아가거나 관절이 비정상적으로 꺾입니다.
**원인**: 물리 계산 타임스텝(`dt`)에 비해 모터 출력(Gain 값)이 너무 높게 설정되어 수치적 폭발이 일어난 현상입니다.  
**해결 방법**:
로봇 URDF/USD 파일 내의 `stiffness`(강도)와 `damping`(감쇠) 비율을 1/2 수준으로 하향 조정하거나, Physics Setting에서 Substeps 값을 `4`에서 `8` 이상으로 늘려주세요.

---

### Q3. 파이썬 실행 시 `ModuleNotFoundError: No module named 'omni'` 에러가 납니다.
**원인**: Isaac Sim 내부 파이썬 환경이 아닌 시스템 기본 Python 환경에서 스크립트를 구동했기 때문입니다.  
**해결 방법**:
Conda 환경이 활성화된 상태에서 Isaac Sim이 제공하는 전용 파이썬 wrapper 스크립트를 사용하거나, PYTHONPATH 환경 변수에 Omniverse 경로를 등록해야 합니다.

```bash
# Isaac Sim 전용 파이썬 경로로 직접 실행하는 방법 (Windows 예시)
C:\Users\<사용자명>\AppData\Local\ov\pkg\isaac-sim-4.x.x\python.bat scripts/train.py
```
