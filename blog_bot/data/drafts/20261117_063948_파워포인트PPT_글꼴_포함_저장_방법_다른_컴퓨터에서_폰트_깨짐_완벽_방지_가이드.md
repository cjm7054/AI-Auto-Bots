# 파워포인트(PPT) 글꼴 포함 저장 방법: 다른 컴퓨터에서 폰트 깨짐 완벽 방지 가이드

중요한 발표나 클라이언트 미팅을 앞두고 열심히 만든 PPT 발표 자료를 발표장의 다른 컴퓨터에서 열었을 때, 텍스트 줄바꿈이 흐트러지고 폰트가 굴림체나 바탕체로 흉하게 바뀌어 당황했던 경험이 있으신가요? 

이러한 현상은 발표용 PC에 작업자가 사용한 폰트(글꼴)가 설치되어 있지 않아서 발생하는 전형적인 문제인 **'폰트 유실(깨짐) 현상'**입니다. 

이 문제는 PPT 파일 자체에 **'글꼴 포함 저장'** 옵션을 설정해 두는 것만으로 100% 방지할 수 있습니다. 클릭 몇 번으로 다른 어떤 컴퓨터에서 발표하더라도 내가 디자인한 글꼴과 레이아웃을 그대로 유지하는 핵심 설정법과 트러블슈팅 꿀팁을 명확하게 정리해 드립니다.

---

## 1단계: 폰트 깨짐의 원인과 저장 전 필수 체크 사항

PPT 폰트가 깨지는 이유를 정확히 이해하면 향후 발생할 수 있는 여러 작업 오류를 사전에 예방할 수 있습니다.

### 폰트 유실이 발생하는 구조적 이유
파워포인트는 기본적으로 문서 내 텍스트 정보를 렌더링할 때 **현재 문서를 열어보고 있는 컴퓨터의 OS에 설치된 폰트 파일**을 참조합니다. 내가 내 컴퓨터에 예쁜 상업용 폰트(예: 나눔스퀘어, 프리텐다드 등)를 설치하여 작업했더라도, 발표장의 PC나 상대방의 노트북에 해당 폰트가 없다면 파워포인트는 시스템 기본 폰트(굴림, 맑은 고딕, Arial 등)로 대체하여 보여줍니다. 이 과정에서 글자의 크기와 자간이 달라져 자막이나 텍스트 상자가 삐져나가는 현상이 발생합니다.

### 작업 전 필수 확인 사항 (TTF vs OTF)
파워포인트의 '글꼴 포함 저장' 기능은 모든 폰트에서 작동하지 않을 수 있습니다. 폰트를 다운로드하여 설치할 때 아래 사항을 반드시 확인하세요.

1. **폰트 형식(TTF 권장):** 
   - **TTF (TrueType Font):** 파워포인트 글꼴 포함 저장 기능과 100% 완벽하게 연동됩니다.
   - **OTF (OpenType Font):** 인쇄/디자인용 폰트로, MS 오피스 버전이나 운영체제 환경에 따라 글꼴 포함 저장이 지원되지 않거나 읽기 전용으로만 저장되는 제한이 자주 발생합니다. **PPT용 폰트는 가급적 TTF 파일로 설치하세요.**
2. **폰트 라이선스 권한:** 
   - 폰트 제작자가 저작권 설정에서 '포함 가능(Installable / Editable)' 권한을 부여한 폰트만 파일에 저장됩니다. '포함 제한(Restricted)' 폰트는 저장 시 에러 메시지가 출력됩니다.

## 2단계: 파워포인트 글꼴 포함 저장 단계별 절차 (Step-by-Step)

Microsoft 365 및 PowerPoint 2016, 2019, 2021, 2024 등 대부분의 최신 윈도우용 파워포인트 버전에서 동일하게 적용되는 표준 설정 절차입니다.

### Step 1. 파워포인트 옵션 창 열기
1. 작성 완료되었거나 작업 중인 PPT 파일을 엽니다.
2. 화면 좌측 상단 메뉴 바에서 **[파일]** 탭을 클릭합니다.
3. 좌측 최하단에 위치한 **[옵션]**을 클릭합니다. (단축키: `Alt` -> `F` -> `T`)

[캡처 화면 설명: 파워포인트 메인 화면 좌측 상단 '파일' 메뉴 클릭 후 나타나는 좌측 하단 탭 메뉴 중 '옵션' 아이콘 위치]

### Step 2. 저장 옵션 메뉴 진입
1. 'PowerPoint 옵션' 팝업 창이 뜨면 좌측 카테고리 메뉴에서 **[저장]** 항목을 선택합니다.
2. 오른쪽 스크롤을 최하단으로 내려 **'이 프레젠테이션 공유 시 보존 성향'** 섹션을 찾습니다.

[캡처 화면 설명: PowerPoint 옵션 창의 좌측 '저장' 탭이 활성화되어 있고, 우측 화면 맨 아래에 '이 프레젠테이션 공유 시 보존 성향' 영역이 보이는 상태]

### Step 3. '파일에 글꼴 포함' 옵션 활성화 및 세부 옵션 선택
1. **[파일에 글꼴 포함(E)]** 체크박스에 체크 표시를 합니다.
2. 하단의 두 가지 세부 라디오 버튼 중 목적에 맞는 옵션을 선택합니다.

[캡처 화면 설명: '파일에 글꼴 포함' 체크박스가 체크되어 있고, 하단에 두 개의 선택지 라디오 버튼이 활성화된 화면]

* **옵션 A: 프레젠테이션에 사용된 문자만 포함(파일 용량을 줄여줌)**
  * **용도:** 완성된 발표용 자료이며, 발표 현장에서 텍스트를 수정할 일이 없을 때 선택합니다.
  * **장점:** 파일 용량 증가폭이 적어 전송이 빠릅니다.
* **옵션 B: 모든 문자 포함(다른 사람이 편집할 수 있음)**
  * **용도:** 타인에게 전달하여 공동 작업을 해야 하거나, 현장에서 오타 수정 등 텍스트 편집이 필요한 경우 선택합니다.
  * **장점:** 폰트가 설치되어 있지 않은 다른 PC에서도 해당 글꼴로 텍스트 추가 및 수정이 가능합니다. (단, 용량이 상대적으로 증가함)

### Step 4. 설정 저장 및 문서 재저장
1. 우측 하단의 **[확인]** 버튼을 눌러 옵션 창을 닫습니다.
2. 키보드의 `Ctrl + S` 키를 누르거나 **[파일] > [저장]**을 눌러 변경된 설정을 문서에 최종 반영합니다.

## 3단계: 실무 활용 옵션 비교표 및 꿀팁

상황에 따라 어떤 방식으로 폰트를 관리하는 것이 효율적인지 아래 비교표를 통해 한눈에 확인하세요.

### 글꼴 저장 및 대안 옵션 비교표

| 구분 | 프레젠테이션 사용 문자만 포함 | 모든 문자 포함 (편집 가능) | PDF 변환 저장 | 폰트 이미지/도형화 |
| :--- | :--- | :--- | :--- | :--- |
| **기본 설정값** | 비활성화 (체크 해제) | 비활성화 (체크 해제) | N/A | N/A |
| **추천 상황** | 단순 발표용 PPT 전달 시 | 팀원 간 공동 편집 작업 시 | 발표 전용 (수정 불필요) | 폰트 포함 저장이 막혔을 때 |
| **파일 용량** | 소폭 증가 (+1~5MB) | 대폭 증가 (+10~30MB 이상) | 압축되어 보통 유지를 원함 | 페이지 수에 따라 용량 커짐 |
| **텍스트 수정** | 불가 (기존 글자 외 수정 제한) | 가능 (상대방 PC에서도 수정 가능) | 불가 | 불가 |
| **안정성** | 높음 (95%) | 높음 (95%) | **완벽 (100%)** | **완벽 (100%)** |

### 💡 실무 생산성을 높이는 3가지 최적화 꿀팁

1. **발표용 최종 파일은 항상 'PDF 파일'을 비상용으로 함께 준비하세요.**
   - 아무리 폰트를 포함해 저장했더라도 발표장 PC의 파워포인트 버전 오류나 OS 차이(Mac OS 등)로 폰트 렌더링 방식이 다를 수 있습니다. `Ctrl + Shift + S` (다른 이름으로 저장)를 눌러 **PDF 형식으로 추가 저장**해두면 최악의 상황에서도 레이아웃 깨짐 없는 완벽한 발표가 가능합니다.

2. **작업 시작 전 폰트 파일 형식(.ttf)을 반드시 확인하세요.**
   - 무료 폰트 다운로드 사이트(눈누, 구글 폰트 등)에서 다운로드할 때 설치 파일 확장자가 `.otf`인지 `.ttf`인지 확인하고, 오피스 문서용으로는 항상 **TTF** 형태를 우선 설치하여 작업하는 습관을 들이세요.

3. **기본 폰트를 지정하여 작업 시간을 단축하세요.**
   - 자주 사용하는 텍스트 상자를 우클릭한 후 **[기본 텍스트 상자로 설정]**을 해두면 새 텍스트 상자를 만들 때마다 매번 폰트를 변경해야 하는 번거로움을 줄일 수 있습니다.

## 4단계: 자주 발생하는 오류 및 트러블슈팅 FAQ

글꼴 포함 저장을 진행하는 과정에서 가장 자주 접하게 되는 3가지 오류와 명쾌한 해결책입니다.

### Q1. "이 프레젠테이션과 함께 저장할 수 없는 글꼴이 있습니다." 에러 메시지가 떠요.
**A:** 이 문제는 사용된 폰트의 라이선스 권한에 **'포함 제한(Restricted)'** 속성이 걸려 있거나, **OTF 폰트**가 포함되어 있을 때 나타납니다.

* **해결 방법 1 (폰트 교체):** 
  - 파워포인트 메뉴 **[홈] > [편집] 그룹 > [바꾸기] 옆 화살표 > [글꼴 바꾸기]**를 클릭합니다.
  - 문제 발생 폰트를 상업적 이용 및 포함 저장이 허용된 맑은 고딕, 나눔스퀘어(TTF), 프리텐다드(TTF) 등으로 일괄 변경합니다.
* **해결 방법 2 (도형 변환):** 
  - 폰트를 바꿀 수 없는 로고나 타이틀 텍스트라면, 텍스트 상자와 도형을 함께 선택한 후 **[도형 서식] > [도형 병합] > [조각] 또는 [합치기]**를 실행하여 텍스트를 벡터 도형 아웃라인으로 변환하면 폰트 제한 없이 그대로 유지됩니다.

### Q2. 글꼴을 포함했더니 PPT 파일 용량이 50MB 이상으로 너무 커졌습니다.
**A:** '모든 문자 포함' 옵션을 선택했거나, 굵기별(Bold, Light, Regular) 폰트 파일이 통째로 내장되어 발생한 현상입니다.

* **해결 방법:** 
  - **[파일] > [옵션] > [저장]**으로 들어간 뒤, 세부 옵션을 **'프레젠테이션에 사용된 문자만 포함'**으로 변경하고 재저장해 보세요. 문서 내 실제로 쓰인 글자 데이터만 저장되므로 용량이 대폭 줄어듭니다.

### Q3. 윈도우(Windows) PC에서 글꼴을 포함하여 저장한 PPT를 맥북(Mac)에서 열었더니 폰트가 깨집니다.
**A:** 윈도우와 Mac OS 간의 파워포인트 폰트 처리 엔진이 서로 완전히 동일하지 않기 때문에 발생하는 교차 플랫폼 호환성 이슈입니다.

* **해결 방법:** 
  - 맥북으로 전달하여 발표하거나 검토를 받아야 하는 문서라면 폰트 포함 PPT 저장과 함께 반드시 **PDF 문서로 내보내어 전달**하거나, 구글 슬라이드(Google Slides)로 업로드하여 웨일/크롬 웹 브라우저 기반으로 열어보는 것이 가장 안전합니다.

## 요약 및 마무리

파워포인트 폰트 깨짐 방지의 핵심은 딱 3가지만 기억하시면 됩니다.

1. 폰트 설치 시 **.TTF 파일**을 우선 사용할 것
2. 작업 완료 후 **[파일] > [옵션] > [저장] > [파일에 글꼴 포함]** 체크
3. 중요 발표 시에는 비상용 **PDF 파일**을 반드시 함께 백업할 것

설정 과정을 따라 해보시다가 특정 폰트에서 에러가 발생하거나 캡처 이미지 경로와 다른 부분이 있다면 댓글로 문의를 남겨주세요. 빠르게 답변해 드리겠습니다.
