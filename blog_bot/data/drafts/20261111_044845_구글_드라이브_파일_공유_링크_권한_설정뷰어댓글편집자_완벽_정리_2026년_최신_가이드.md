# 구글 드라이브 파일 공유 링크 권한 설정(뷰어/댓글/편집자) 완벽 정리: 2026년 최신 가이드

팀 프로젝트를 진행하거나 외부 클라이언트에게 대용량 자료를 전달할 때 구글 드라이브(Google Drive)는 이제 선택이 아닌 필수가 되었습니다. 하지만 링크를 생성해 전달한 뒤 **"수정이 안 됩니다"**, **"권한이 없다고 뜹니다"**, 또는 반대로 **"모르는 사람이 원본 파일을 삭제했습니다"**와 같은 아찔한 상황을 한 번쯤 겪어보셨을 겁니다. 

구글 드라이브의 공유 기능은 강력하지만, 그만큼 권한 설정 체계를 정확히 이해하지 못하면 보안 사고나 업무 지연으로 이어지기 십상입니다. 

2026년 현재 적용되는 구글 드라이브 최신 인터페이스를 기준으로, 파일 공유 링크의 기본 개념부터 뷰어·댓글·편집자 권한의 차이, 그리고 실무에서 겪는 트러블슈팅까지 한눈에 파악할 수 있도록 상세히 안내해 드리겠습니다. 이 글을 끝까지 읽으시면 더 이상 권한 설정 때문에 당황하는 일은 없을 것입니다.

---

## 1단계: 왜 권한 설정 오류가 발생할까? (사전 준비 및 원인 분석)

구글 드라이브에서 파일을 공유할 때 가장 많이 범하는 실수는 **'링크를 가진 모든 사용자'**와 **'특정 사용자'**의 개념을 혼동하거나, 구글 계정이 없는 상대방에게 권한을 부여하려 할 때 발생합니다.

### 1. 주요 권한 오류 원인
* **조직 외부 공유 제한:** 회사 계정(Google Workspace)을 사용하는 경우, 보안 정책상 외부 조직원에게 '편집자' 권한을 주는 것이 기본적으로 차단되어 있을 수 있습니다.
* **뷰어 상태에서 수정 시도:** 상대방이 단순히 파일을 열어보기만 할 수 있는 '뷰어' 링크로 접속해 놓고 수정하려다 권한 거부(Access Denied) 창을 마주하는 경우입니다.
* **상속 권한 문제:** 상위 폴더의 권한 설정이 하위 파일에 그대로 적용되어 의도치 않게 전체 공개되거나 반대로 접근이 막히는 경우입니다.

### 2. 준비물
* 구글 계정 (개인용 @gmail.com 또는 기업용 Google Workspace 계정)
* 공유할 파일 또는 폴더 (문서,스프레드시트, PDF 등)

## 2단계: 단계별 파일 공유 링크 설정 방법 (Step-by-Step)

자, 이제 실제로 구글 드라이브에서 링크를 생성하고 권한을 세부적으로 설정하는 과정을 순서대로 따라 해 보겠습니다. PC 웹 브라우저 화면을 기준으로 설명합니다.

### Step 1: 공유할 파일 선택 및 공유 메뉴 진입하기
1. 웹 브라우저를 열고 [Google Drive](https://drive.google.com)에 접속하여 로그인합니다.
2. 공유하고자 하는 파일이나 폴더를 마우스 우클릭합니다.
3. 팝업 메뉴에서 **[공유]** > **[공유]**를 차례대로 클릭합니다. (또는 파일을 선택한 상태 화면 우측 상단의 사람 모양 아이콘이나 단축키를 활용할 수도 있습니다.)
   - *[캡처 화면 설명]*: 파일 우클릭 시 파란색 사람 아이콘과 함께 '공유' 글자가 표시되는 메뉴 상자를 볼 수 있습니다.

### Step 2: '일반 액세스' 권한 변경하기 (링크가 있는 모든 사용자 설정)
공유 창이 열리면 하단에 있는 '일반 액세스' 영역을 주목해야 합니다. 링크를 가진 사람이라면 누구에게나 권한을 줄 것인지, 아니면 특정 사람에게만 허용할 것인지를 결정하는 단계입니다.
1. '일반 액세스' 아래에 있는 드롭다운 메뉴(기본값: '제한됨')를 클릭합니다.
2. **[링크가 있는 모든 사용자]**를 선택합니다.
   - *[캡처 화면 설명]*: '제한됨' 또는 '내 조직의 이름'으로 되어 있는 드롭다운을 클릭하면 전 세계 누구나 접근 가능하게 바꿀 수 있는 옵션 리스트가 나타납니다.

### Step 3: 세부 역할 지정하기 (뷰어 / 댓글 작성자 / 편집자)
링크가 있는 모든 사용자로 설정했다면, 그 우측에 있는 권한 등급을 선택해야 합니다. 여기서 세 가지 선택지가 나옵니다.
1. **뷰어 (Viewer):** 파일을 읽기만 할 수 있으며, 다운로드나 인쇄는 허용되지만 내용 수정은 불가능합니다.
2. **댓글 작성자 (Commenter):** 파일을 보고 의견(댓글)을 남길 수 있지만, 원본 문서의 텍스트나 데이터를 직접 수정할 수는 없습니다.
3. **편집자 (Editor):** 파일의 내용을 수정, 삭제, 추가할 수 있으며 다른 사람에게 권한을 다시 공유하는 것도 가능해집니다.
4. 원하는 권한을 선택한 후 우측 하단의 **[링크 복사]** 버튼을 누릅니다.

### Step 4: 완료 및 링크 전달
1. 링크가 클립보드에 복사되었다는 알림이 뜨면 **[완료]** 버튼을 누릅니다.
2. 카카오톡, 이메일, 슬랙(Slack) 등의 메신저 창에 `Ctrl + V`를 눌러 상대방에게 링크를 전달합니다.

## 3단계: 실무 활용 꿀팁 및 권한 옵션 비교표

구글 드라이브를 업무에 100% 활용하기 위해서는 상황에 맞는 정확한 권한을 선택해야 합니다. 무조건 '편집자' 권한을 주는 것은 보안상 매우 위험합니다. 아래 비교표를 보고 상황에 맞는 최적의 설정을 선택해 보세요.

| 설정 항목 | 기본값 | 권장 설정 (외부 협업 시) | 효과 및 특징 |
| :--- | :--- | :--- | :--- |
| **제한됨** | O | 내부 기밀 문서 / 인사평가 자료 | 초대받은 특정 이메일 계정 사용자만 접근 가능 (보안성 최우상) |
| **뷰어** | X | 최종 보고서 배포 / 가이드라인 공유 | 수정 위험 없이 안전하게 내용 열람 및 다운로드 가능 |
| **댓글 작성자** | X | 기획서 피드백 수집 / 디자인 시안 검토 | 원본 훼손 없이 문서 위젯에 의견을 남기고 소통 가능 |
| **편집자** | X | 공동 작업 스프레드시트 / 팀 프로젝트 | 실시간 동시 편집 및 파일 관리 가능 (단, 신뢰할 수 있는 대상에게만 부여) |

### 💡 실무 전문가 꿀팁
* **만료일 설정 활용하기:** Google Workspace 유료 버전을 사용 중이라면, 특정 협력사 직원에게 임시로 권한을 부여할 때 '만료일 설정'을 통해 일정 시간이 지나면 자동으로 권한이 회수되도록 설정할 수 있습니다. 공유 창 내 이메일 주소 옆 시계 모양 아이콘을 확인해 보세요.
* **다운로드/인쇄 금지 설정:** 뷰어 권한으로 공유할 때, 문서 소유자는 고급 설정(톱니바퀴 아이콘)에서 **'뷰어 및 댓글 작성자가 다운로드, 인쇄, 복사 옵션 보기'** 체크를 해제할 수 있습니다. 이를 통해 중요한 자료의 무단 유출을 어느 정도 방지할 수 있습니다.

## 4단계: 자주 발생하는 오류 및 트러블슈팅 FAQ

실무에서 구글 드라이브 링크를 공유하다 보면 예상치 못한 문제에 부딪히곤 합니다. 독자분들이 가장 많이 겪는 3가지 질문과 명쾌한 해결 방법을 정리했습니다.

### Q1. 링크를 주었는데 상대방이 "권한이 없습니다(Access Denied)"라고 뜹니다.
* **원인:** 회사업무용 계정(Google Workspace)에서 보안 가이드라인으로 인해 외부 조직 메일(@gmail.com 등)에 대한 외부 공유를 원천 차단해 놓았기 때문입니다.
* **해결 방법:** 구글 드라이브 관리자에게 문의하여 외부 공유 허용 정책을 요청하거나, 개인 Gmail 계정으로 파일을 복사(이동)한 뒤 해당 개인 계정에서 다시 링크를 생성해 공유해야 합니다.

### Q2. '편집자' 권한을 주었는데 상대방이 파일을 삭제해버렸습니다.
* **원인:** 최상위 폴더에 '편집자' 권한을 주면, 하위의 모든 개별 파일뿐만 아니라 폴더 자체까지 삭제하거나 이동할 수 있는 권한이 부여되기 때문입니다.
* **해결 방법:** 당황하지 말고 구글 드라이브 좌측 메뉴의 **[휴지통]**으로 이동합니다. 삭제된 파일이나 폴더를 우클릭하여 **[복원]**을 누르면 원래 위치로 되돌아옵니다. 앞으로는 폴더 전체 대신 특정 파일 단위로만 편집 권한을 부여하거나, '댓글 작성자' 권한을 활용하는 것이 안전합니다.

### Q3. 로그인하라고 창이 계속 뜹니다. 링크만 누르면 바로 열리게 할 수는 없나요?
* **원인:** 일반 액세스 권한이 '링크가 있는 모든 사용자'로 설정되어 있더라도, 구글 드라이브의 일부 대용량 파일이나 민감한 형식은 보안상 구글 계정 로그인을 요구할 수 있습니다.
* **해결 방법:** 시크릿 창(Incognito Mode, 단축키 `Ctrl + Shift + N`)을 열어 해당 링크를 복사·붙여넣기 해보세요. 본인이 로그인이 안 된 상태에서 테스트해 보는 가장 확실한 방법입니다. 만약 여전히 로그인을 요구한다면 권한 설정이 '제한됨'으로 풀려있는지 재확인해야 합니다.

## 결론

구글 드라이브의 파일 공유 링크 권한 설정은 단순히 버튼 몇 번 누르는 것 이상의 의미를 가집니다. **'뷰어'**, **'댓글 작성자'**, **'편집자'**의 개념만 명확히 이해하고 상황에 맞게 적용한다면, 불필요한 수정 사고를 방지하고 협업의 생산성을 극대화할 수 있습니다. 

오늘 알아본 단계별 가이드를 바탕으로 업무 중 안전하고 스마트하게 클라우드 자원을 공유해 보시길 바랍니다. 적용해 보시다가 막히는 단계가 있거나 추가로 궁금한 점이 있다면 언제든지 아래 댓글로 남겨주시기 바랍니다.
