# 크롬 즐겨찾기 북마크 내보내기 및 새 PC 가져오기 백업 완전 정복

새 컴퓨터를 구매했거나 포맷을 진행할 때 가장 난감한 순간 중 하나는 수년간 차곡차곡 쌓아온 브라우저의 '즐겨찾기(북마크)' 목록이 사라질까 봐 걱정되는 때입니다. 자주 방문하는 업무용 사이트, 금융 기관, 참고용 블로그 URL을 일일이 다시 찾아 저장하려면 엄청난 시간과 노력이 소모됩니다.

구글 계정 로그인 동기화 기능이 존재하지만, 회사 보안 정책으로 인해 로그인이 제한된 PC 환경이거나 계정이 꼬여 기존 데이터가 덮어씌워지는 불상사를 방지하려면 ** HTML 파일 형태의 직접 백업 방식**이 가장 확실하고 안전합니다.

본 가이드에서는 단 3분 만에 크롬의 모든 북마크를 HTML 파일로 안전하게 내보내고, 새 PC로 손실 없이 100% 그대로 복구하는 전체 과정을 상세히 안내합니다.

---

## 1단계: 북마크 백업 전 사전 준비 사항

백업을 시작하기 전, 데이터 손실 위험을 줄이고 작업 시간을 단축하기 위해 아래 사전 체크리스트를 확인해야 합니다.

### 준비물 및 확인 사항
1. **현재 사용 중인 구글 크롬 브라우저**: 최신 버전을 유지하는 것이 좋지만, 구버전이라도 메뉴 위치는 거의 동일합니다.
2. **백업 파일을 저장할 매체**: USB 메모리, 외장 하드, 또는 개인 클라우드(구글 드라이브, 네이버 MYBOX, 카카오톡 나와의 채팅방 등) 중 하나를 준비합니다.
3. **단축키 숙지**: 크롬 북마크 관리자로 바로 이동하는 단축키인 `Ctrl + Shift + O` (Mac 사용자: `Cmd + Option + B`)를 기억해 두면 작업 속도가 훨씬 빨라집니다.

---

## 2단계: 핵심 단계별 해결 절차 (Step-by-Step)

크롬 북마크 이동은 크게 **[기존 PC에서 내보내기]**와 **[새 PC에서 가져오기]** 2단계로 진행됩니다. 화면 안내대로 차근차근 따라 해 보세요.

### [파트 1] 기존 PC에서 북마크 내보내기 (Backup)

#### Step 1. 크롬 북마크 관리자 접속
1. 크롬 브라우저를 실행합니다.
2. 우측 상단의 **점 3개 아이콘(⋮)**을 클릭합니다.
3. 메뉴 드롭다운에서 **[북마크 및 목록]** > **[북마크 관리자]** 경로로 이동합니다.
   *(단축키: Windows `Ctrl + Shift + O` / Mac `Cmd + Option + B` 입력시 즉시 이동)*

[캡처 화면 설명: 크롬 우측 상단 점 3개 버튼을 누른 뒤 나타나는 메뉴에서 '북마크 및 목록'에 마우스를 올려 오른쪽 하위 메뉴의 '북마크 관리자'를 선택하는 화면]

#### Step 2. 백업 파일(HTML) 생성 및 저장
1. 북마크 관리자 페이지 상단 우측의 **파란색 띠 또는 우측 상단에 위치한 점 3개 아이콘(⋮)**을 클릭합니다. (브라우저 주소창 아래의 점 3개가 아닌, 관리자 페이지 내부의 점 3개 버튼입니다.)
2. 메뉴 중 **[북마크 내보내기]** 옵션을 클릭합니다.
3. '다른 이름으로 저장' 창이 나타나면 저장 위치(예: 바탕화면 또는 USB)를 지정합니다.
4. 파일 이름은 기본값인 `bookmarks_2026_X_X.html` 형태 그대로 유지한 후 **[저장]**을 누릅니다.

[캡처 화면 설명: 북마크 관리자 화면 우측 상단의 점 3개 버튼을 눌러 드롭다운 메뉴 최하단의 '북마크 내보내기'를 클릭하고 파일 저장 창이 열리는 화면]

---

### [파트 2] 새 PC로 북마크 가져오기 (Restore)

내보낸 `bookmarks.html` 파일을 USB나 클라우드를 통해 새 PC로 옮긴 뒤 진행합니다.

#### Step 1. 새 PC 크롬에서 가져오기 메뉴 실행
1. 새 PC에서 크롬을 엽니다.
2. 우측 상단 **점 3개 아이콘(⋮)** 클릭 > **[북마크 및 목록]** > **[북마크 및 설정 가져오기...]**를 선택합니다.

[캡처 화면 설명: 새 PC의 크롬 메뉴에서 '북마크 및 목록' 하위의 '북마크 및 설정 가져오기...' 메뉴를 클릭하는 화면]

#### Step 2. 백업 파일 선택 및 복구 완료
1. '북마크 및 설정 가져오기' 팝업 창이 뜨면 드롭다운 메뉴에서 **[HTML 파일 북마크에 추가]**를 선택합니다.
2. 아래의 **[파일 선택]** 버튼을 클릭합니다.
3. 이전 PC에서 옮겨온 `bookmarks.html` 파일을 찾아서 선택한 후 **[열기]**를 누릅니다.
4. "북마크 및 설정이 준비되었습니다."라는 안내 문구가 나오면 **[완료]**를 누릅니다.

[캡처 화면 설명: 팝업창 드롭다운 선택 상자에서 'HTML 파일 북마크에 추가'를 선택하고 파란색 '파일 선택' 버튼을 누르는 화면]

#### Step 3. 가져온 북마크 확인 및 북마크바 표시
1. 단축키 `Ctrl + Shift + B` (Mac: `Cmd + Shift + B`)를 눌러 브라우저 상단에 **북마크바**가 보이도록 설정합니다.
2. 북마크바에 **[가져온 북마크]** 폴더가 생성되었는지 확인하고, 내부 폴더들을 마우스 드래그 앤 드롭으로 원하는 위치에 배치합니다.

## 3단계: 백업 방식별 비교 및 실무 꿀팁

크롬 북마크를 관리하는 방법은 HTML 내보내기 외에도 계정 동기화 방식이 있습니다. 환경과 상황에 맞춰 가장 적절한 방식을 선택할 수 있도록 비교 표를 제시합니다.

### 📊 크롬 북마크 백업 방식 비교표

| 비교 항목 | HTML 파일 내보내기/가져오기 | 구글 계정 동기화 (Sync) | 서드파티 확장프로그램 사용 |
| :--- | :--- | :--- | :--- |
| **추천 환경** | 보안 PC, 공용 PC, 계정 비로그인 환경 | 개인용 PC, 스마트폰, 태블릿 간 연동 | 다중 브라우저(웨일, 파이어폭스 등) 교차 사용자 |
| **인터넷 연결** | 오프라인 상태에서도 가능 | 필수 (Google 서버 통신) | 필수 |
| **데이터 안전성** | 100% 안전 (파일 직접 보관) | 계정 꼬임 시 데이터 덮어쓰기 위험 존재 | 확장프로그램 서비스 종료 시 위험 |
| **작업 소요시간** | 약 1~3분 | 로그인 즉시 (수 초 이내) | 초기 설정 필요 (3~5분) |
| **권장 설정** | **주 1회 또는 포맷 직전 필수 실행** | 개인 기기 전용으로 권장 | 비권장 |

### 💡 실무 생산성을 높이는 크롬 북마크 활용 꿀팁
- **정기적인 디렉토리 정돈**: 백업을 진행하기 직전, '북마크 관리자(`Ctrl + Shift + O`)'에서 더 이상 접속되지 않는 폐쇄 사이트나 중복 등록된 URL을 삭제하면 백업 파일 용량이 줄어들고 새 PC 환경이 훨씬 쾌적해집니다.
- **파이어폭스 / 웨일 / 엣지 호환성**: 크롬에서 내보낸 `bookmarks.html` 파일은 네이버 웨일, 마이크로소프트 엣지, 파이어폭스 등 Chromium 기반의 모든 다른 브라우저에서도 그대로 가져와 호환하여 사용할 수 있습니다.

## 4단계: 자주 발생하는 오류 및 트러블슈팅 FAQ

북마크를 옮기는 과정에서 독자들이 가장 자주 겪는 3가지 문제 상황과 즉각적인 해결책입니다.

### Q1. HTML 파일을 가져왔는데 북마크바에 기존 폴더 구조가 안 보이고 다 사라진 것 같아요.
> **답변:** 데이터가 사라진 것이 아닙니다. HTML 파일로 가져온 북마크는 기본적으로 북마크바 맨 우측에 **[가져온 북마크]**라는 별도의 폴더 형태로 생성되어 들어갑니다.  
> `Ctrl + Shift + O`를 눌러 북마크 관리자로 들어간 후, [가져온 북마크] 폴더 내부로 들어가 폴더 전체를 선택하고 왼쪽의 '북마크바' 영역으로 마우스 드래그하여 옮겨주시면 이전과 똑같이 상단바에 노출됩니다.

### Q2. 기존 PC의 크롬 브라우저가 아예 켜지지 않는 먹통 상태입니다. HTML 내보내기를 못 하는데 어떻게 백업하나요?
> **답변:** 크롬 앱이 실행되지 않더라도 윈도우 탐색기 경로를 통해 북마크 원본 파일 데이터베이스를 직접 추출할 수 있습니다.  
> 1. 키보드의 `Win + R`을 눌러 실행 창을 엽니다.  
> 2. `%LOCALAPPDATA%\Google\Chrome\User Data\Default` 경로를 입력하고 엔터를 누릅니다.  
> 3. 해당 폴더 안에서 확장자가 없는 **`Bookmarks`** 파일 및 `Bookmarks.bak` 파일을 복사하여 외장 메모리에 백업합니다.  
> 4. 새 PC의 동일한 경로에 해당 파일을 덮어씌우면 크롬을 켜지 않고도 완벽히 복구됩니다.

### Q3. 회사 PC에서 북마크를 가져왔더니 개인 구글 계정에 있던 북마크와 섞여서 엉망이 되었습니다. 분리할 수 있나요?
> **답변:** 업무용 사이트와 개인용 즐겨찾기가 섞이지 않게 하려면 크롬의 **'프로필 분리'** 기능을 활용해야 합니다.  
> 크롬 우측 상단의 프로필 동그라미 아이콘을 클릭한 후 하단의 **[+ 추가]** 버튼을 눌러 '업무용' 프로필을 새로 만드세요. 그 후 해당 독립된 프로필 내에서만 가져오기를 진행하면 개인 데이터와 완벽히 격리된 환경에서 사용할 수 있습니다.

---

컴퓨터 교체나 시스템 초기화 시 북마크 백업은 선택이 아닌 필수 작업입니다. 본 가이드에서 안내해 드린 HTML 내보내기 방식을 이용해 중요한 웹 자산과 업무 링크를 안전하게 보관해 보시기 바랍니다.

백업 및 가져오기를 직접 적용해 보시다가 특정 메뉴가 보이지 않거나 막히는 단계가 있다면 댓글로 질문을 남겨주세요. 확인 후 친절히 답변해 드리겠습니다.
