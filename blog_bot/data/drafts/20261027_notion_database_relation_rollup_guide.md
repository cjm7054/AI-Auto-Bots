# 노션(Notion) 데이터베이스 관계형(Relation) 및 롤업(Rollup) 속성 실전 활용 가이드

올인원 생산성 도구인 노션(Notion)을 단순한 메모장이나 텍스트 정리용으로만 사용하고 있다면, 노션의 진정한 잠재력 중 10%도 활용하지 못하고 있는 것입니다.

노션이 일반 메모 앱과 결정적으로 차별화되는 핵심 기능은 바로 **데이터베이스 간의 '관계형(Relation)' 연결**과 이를 기반으로 데이터를 계산·취합하는 **'롤업(Rollup)' 속성**입니다. 이 두 가지 기능을 조합하면 복잡한 프로젝트 관리 시스템, 고객 관리(CRM), 일정 연동 대시보드를 엑셀 함수 없이도 직관적으로 구축할 수 있습니다.

이번 가이드에서는 노션 초보자도 10분 만에 마스터할 수 있도록, **'프로젝트 관리'와 '세부 업무(태스크)' 데이터베이스를 연결하는 실전 예제**를 바탕으로 관계형과 롤업의 개념 및 설정 절차를 완벽하게 정리해 드립니다.

---

## 1. 관계형(Relation)과 롤업(Rollup)의 기본 개념 이해

설정에 들어가기 전 두 속성의 상호작용 원리를 이해하면 어떤 업무에도 응용할 수 있습니다.

* **관계형(Relation)**: 서로 다른 두 데이터베이스의 페이지를 **'줄로 연결'**하는 속성입니다.
  - *예시: 'A 프로젝트' 페이지에 '세부 업무 1, 2, 3' 페이지를 연결*
* **롤업(Rollup)**: 관계형으로 연결된 상대방 데이터베이스에서 **특정 속성값을 가져와 보여주거나 통계(합계, 평균, 완료율 등)를 자동 계산**해 주는 속성입니다.
  - *예시: '세부 업무'들의 진행 상태를 계산하여 'A 프로젝트'에 '전체 진행률 67%'로 자동 표시*

> 📌 **핵심 원칙**: 롤업(Rollup)은 단독으로 생성할 수 없으며, **반드시 먼저 관계형(Relation) 속성이 연결되어 있어야만** 활성화됩니다.

---

## 2. 3단계 실전 셋업: 프로젝트-태스크 연동 시스템 만들기

### Step 1. 두 개의 기본 데이터베이스 준비하기

먼저 연동할 두 개의 데이터베이스를 생성합니다.

1. 노션 빈 페이지에 `/표`를 입력하고 **[표 보기 - 데이터베이스]**를 선택합니다.
2. 첫 번째 데이터베이스 이름을 **[프로젝트 목록]**으로 지정합니다.
   - 속성: 프로젝트명(이름), 담당자(사람)
3. 그 아래에 두 번째 표 데이터베이스를 생성하고 이름을 **[세부 업무 목록]**으로 지정합니다.
   - 속성: 업무명(이름), 상태(상태: 시작 전 / 진행 중 / 완료), 소요시간(숫자)

---

### Step 2. '관계형(Relation)' 속성으로 두 데이터베이스 연결하기

세부 업무가 어느 프로젝트에 속하는지 연결해 줍니다.

1. **[세부 업무 목록]** 데이터베이스 우측 상단의 `+` (새 속성 추가) 버튼을 클릭합니다.
2. 속성 유형 목록에서 **[관계형 (Relation)]**을 선택합니다.
3. 연결할 데이터베이스 검색창에 앞서 만든 **[프로젝트 목록]**을 검색하여 선택합니다.
4. 옵션 설정에서 **[프로젝트 목록에 표시]** 토글을 켜줍니다. (양방향 연결)
5. **[관계형 추가]** 버튼을 클릭합니다.

> 💡 **확인**: 이제 세부 업무 목록에서 프로젝트 셀을 클릭하면 프로젝트 목록의 항목들이 드롭다운으로 뜨며 바로 연결할 수 있습니다.

---

### Step 3. '롤업(Rollup)' 속성으로 진행률 및 소요시간 자동 계산하기

이제 프로젝트 목록에서 세부 업무들의 상태를 자동으로 집계해 봅니다.

#### 예제 A: 세부 업무의 '완료율(퍼센트)' 자동 게이지 표시
1. **[프로젝트 목록]** 데이터베이스로 이동하여 `+` 버튼을 눌러 새 속성을 추가합니다.
2. 속성 유형에서 **[롤업 (Rollup)]**을 선택합니다.
3. 롤업 설정 창에서 다음 3가지를 순서대로 지정합니다:
   - **관계형**: [세부 업무 목록] 선택
   - **속성**: [상태] 선택
   - **계산**: [완료 비율 (Percent checked 또는 Percent per group: 완료)] 선택
4. 표시 형식을 **[막대(Bar)]** 또는 **[원(Ring)]**으로 설정하고 색상을 지정합니다.
5. 이제 세부 업무의 상태가 '완료'로 바뀔 때마다 프로젝트의 진행률 막대가 실시간으로 차오릅니다.

#### 예제 B: 프로젝트별 총 소요시간 '합계(Sum)' 계산
1. 프로젝트 목록에 새 **[롤업]** 속성을 하나 더 추가합니다.
2. 관계형: `[세부 업무 목록]`, 속성: `[소요시간]`, 계산: `[합계 (Sum)]`을 선택합니다.
3. 각 세부 업무에 입력된 시간들이 자동으로 합산되어 프로젝트의 총 투입 시간이 표시됩니다.

## 3. 관계형 vs 롤업 속성 주요 옵션 비교표

| 속성명 | 주요 역할 | 필수 선행 조건 | 추천 계산(연산) 옵션 |
|---|---|---|---|
| **관계형 (단방향)** | 한쪽 DB에서만 상대 DB 페이지 참조 | 대상 DB 존재 | 연산 없음 (링크 연결) |
| **관계형 (양방향)** | 양쪽 DB 모두에서 상호 링크 확인 | 대상 DB 존재 | 연산 없음 (양방향 참조) |
| **롤업 (상태 집계)** | 완료 비율, 미완료 개수 계산 | 관계형 속성 연결 | `완료 비율`, `모두 완료됨` |
| **롤업 (숫자 계산)** | 합계, 평균, 최소/최대값 연산 | 관계형 + 숫자 속성 | `합계`, `평균`, `범위` |
| **롤업 (고유값 추출)** | 연결된 페이지의 카테고리/태그 취합 | 관계형 + 선택 속성 | `고유한 값 표시`, `고유한 값 개수` |

## 4. 자주 발생하는 오류 및 트러블슈팅 FAQ

### Q1. 롤업 속성을 추가하려는데 '사용 가능한 관계형이 없습니다'라고 뜹니다.
롤업은 반드시 관계형 속성을 먼저 생성해야 작동합니다. 데이터베이스에 관계형 속성이 없거나, 관계형 속성을 생성했다가 삭제한 경우 롤업이 생성되지 않으므로 Step 2의 관계형 속성을 먼저 만들어 주시기 바랍니다.

### Q2. 수정한 내용이 롤업 계산에 즉시 반영되지 않습니다.
노션 웹/앱의 일시적인 동기화 지연일 수 있습니다. 단축키 `Ctrl + R` (Mac: `Cmd + R`)을 눌러 노션 화면을 새로고침하면 최신 데이터베이스 계산값이 즉시 반영됩니다.

### Q3. 하나의 세부 업무에 여러 개의 프로젝트를 연결할 수 있나요?
네, 가능합니다. 관계형 속성 설정에서 **[페이지 제한: 제한 없음]**으로 설정하면 한 업무를 여러 프로젝트에 동시 배정할 수 있으며, 엄격한 1:1 관리를 원하시면 **[페이지 제한: 페이지 1개]**로 설정하시면 됩니다.

## 결론 및 실천 팁

노션의 **관계형(Relation)**과 **롤업(Rollup)**은 엑셀의 복잡한 함수를 몰라도 직관적인 마우스 클릭 몇 번으로 프로급 업무 대시보드를 만들어 주는 핵심 기능입니다.

오늘 바로 작은 [프로젝트 목록]과 [세부 업무] 데이터베이스를 만들어 두 테이블을 연결해 보세요. 업무가 체계화되고 진행 상황이 한눈에 들어오는 놀라운 생산성 향상을 경험하실 수 있습니다.

설정 중 막히는 수식이나 특정 대시보드 템플릿 구현에 도움이 필요하시다면 댓글로 질문을 남겨주시면 성심껏 답변해 드리겠습니다.
