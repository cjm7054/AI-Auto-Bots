# 윈도우 11/10 'DNS 서버가 응답하지 않습니다' 인터넷 오류 5단계 완벽 해결 가이드

갑자기 인터넷 우측 하단 네트워크 아이콘에 노란색 경고창이 뜨거나, 웹 브라우저에 **"DNS_PROBE_FINISHED_NXDOMAIN"** 혹은 **"DNS 서버가 응답하지 않습니다"**라는 오류 메시지가 출력되면서 웹사이트 접속이 먹통이 되는 현상은 누구나 한 번쯤 겪는 대표적인 네트워크 장애입니다.

급한 업무를 처리하거나 영상을 시청하던 중 이런 문제가 발생하면 매우 답답합니다. 공유기를 껐다 켜보아도 여전히 동일한 증상이 반복된다면 문제는 네트워크 설정이나 DNS(도메인 네임 시스템) 캐시 꼬임에 있을 확률이 높습니다. 

이 가이드에서는 윈도우(Windows 10/11) 환경에서 해당 오류가 발생하는 명확한 원인을 파악하고, 초보자도 100% 쉽게 따라 할 수 있는 단계별 해결 방법을 제공합니다. 순서대로 적용해 보면서 정상적인 인터넷 환경을 되찾아보세요.

---

## 1단계: DNS 오류 원인 분석 및 사전 점검

DNS(Domain Name System)는 우리가 웹 브라우저에 입력하는 문자 주소(예: `google.com`)를 컴퓨터가 이해할 수 있는 숫자 IP 주소(예: `142.250.206.206`)로 변환해 주는 '인터넷 이정표' 역할을 합니다. 

이 이정표를 제공하는 서버(통신사 또는 지정 DNS 서버)가 응답하지 않거나, 내 PC 내부에 저장된 이정표 정보(DNS 캐시)가 오염되면 인터넷 선이 정상적으로 연결되어 있어도 웹페이지를 열 수 없게 됩니다.

### 주요 발생 원인
- **내부 DNS 캐시 오염:** PC에 저장된 구 버전 네트워크 주소 정보 충돌
- **통신사(ISP) DNS 서버 일시 장애:** KT, SKT, LGU+ 등 통신사 DNS의 일시적 장애
- **네트워크 어댑터 드라이버 오류:** 랜카드 드라이버 손상 또는 꼬임
- **보안 프로그램 interference:** 백신 또는 방화벽의 과도한 네트워크 블로킹

### 본 격적인 조치 전 1분 사전 점검
1. **스마트폰 Wi-Fi 접속 확인:** PC와 동일한 Wi-Fi에 스마트폰을 연결해 봅니다. 스마트폰에서도 인터넷이 안 된다면 PC가 아닌 **모뎀/공유기 문제**입니다. (모뎀과 공유기의 전원 선을 뽑고 1분 후 다시 꽂으세요.)
2. **스마트폰에서는 인터넷이 잘 된다면:** 아래의 2단계 PC 설정 절차를 바로 진행하세요.

---

## 2단계: 핵심 단계별 해결 절차 (Step-by-Step)

가장 간단하고 효과가 빠른 방법부터 순서대로 배치했습니다. 1번 단계부터 차례대로 시도해 보세요.

---

### Step 1. DNS 캐시 재설정 및 네트워크 초기화 (CMD 명령)

PC에 쌓여 있는 잘못된 네트워크 임시 정보를 싹 비워내고 IP를 새로 할당받는 작업입니다. 대부분의 일시적 오류는 이 단계에서 해결됩니다.

1. 키보드의 `Win + S` 키를 누른 후 **'cmd'** 또는 **'명령 프롬프트'**를 검색합니다.
2. 검색 결과에 나온 명령 프롬프트 아이콘을 마우스 우클릭한 뒤 **[관리자 권한으로 실행]**을 클릭합니다.

[캡처 화면 설명: 검색창에 cmd를 입력한 후 오른쪽 메뉴에서 '관리자 권한으로 실행' 버튼에 마우스 커서가 올라가 있는 검은색 콘솔 창 실행 화면]

3. 검은색 명령 프롬프트 창이 뜨면 아래 명령어들을 **한 줄씩 입력하고 Enter**를 누릅니다.

```bash
ipconfig /flushdns
ipconfig /registerdns
ipconfig /release
ipconfig /renew
netsh winsock reset
```

4. 모든 명령어 입력이 완료되면 **"Winsock 카탈로그를 성공적으로 재설정했습니다."**라는 메시지가 출력됩니다.
5. **PC를 재부팅**한 뒤 웹 브라우저 접속을 시도합니다.

---

### Step 2. 신뢰할 수 있는 수동 DNS(구글/클라우드플레어)로 변경

사용 중인 통신사 DNS 서버의 반응이 늦거나 장애가 발생했을 때, 세계에서 가장 빠르고 안정적인 구글(Google) 또는 클라우드플레어(Cloudflare) Public DNS로 변경하는 방법입니다.

1. 키보드 단축키 `Win + R`을 눌러 실행 창을 켭니다.
2. 입력창에 `ncpa.cpl` 을 입력하고 **[확인]**을 누릅니다. (네트워크 연결 제어판이 열립니다.)

[캡처 화면 설명: 실행 창에 ncpa.cpl이 입력되어 있고 확인 버튼을 누르는 직관적인 소형 입력창 화면]

3. 현재 사용 중인 네트워크 어댑터(유선 랜은 **'이더넷'**, 무선은 **'Wi-Fi'**)를 마우스 우클릭 후 **[속성(P)]**을 클릭합니다.
4. 항목 목록에서 **[인터넷 프로토콜 버전 4(TCP/IPv4)]**를 찾아서 클릭하고, 우측 하단의 **[속성(R)]** 버튼을 누릅니다.

[캡처 화면 설명: 이더넷 속성 창에서 목록 중간의 TCP/IPv4 항목이 파란색으로 하이라이트 되어 있고 아래 속성 버튼을 가리키는 화면]

5. 하단의 **[다음 DNS 서버 주소 사용]** 라디오 버튼을 체크합니다.
6. 주소 입력란에 아래 구글 Public DNS 정보를 정확히 입력합니다.
   - **기본 설정 DNS 서버:** `8 . 8 . 8 . 8`
   - **보조 DNS 서버:** `8 . 8 . 4 . 4`
7. **[확인할 때 설정 저장]**에 체크한 후 **[확인]**을 눌러 창을 닫습니다.

---

### Step 3. 인터넷 프로토콜 버전 6 (IPv6) 비활성화

최신 윈도우 환경에서는 IPv6 프로토콜이 기본 활성화되어 있습니다. 그러나 일부 아파트 단자함이나 구형 공유기 환경에서는 IPv6 연결 신호가 꼬여 DNS 응답 오류를 유발합니다.

1. `Win + R` -> `ncpa.cpl` 입력 후 네트워크 연결 창을 열어줍니다.
2. 사용 중인 이더넷 또는 Wi-Fi 우클릭 -> **[속성]**으로 이동합니다.
3. 목록에서 **[인터넷 프로토콜 버전 6(TCP/IPv6)]** 항목의 **체크박스를 해제(체크 비우기)** 합니다.

[캡처 화면 설명: 이더넷 속성 목록 중 '인터넷 프로토콜 버전 6(TCP/IPv6)' 앞의 체크표시 박스가 해제되어 빈칸으로 남아있는 화면]

4. 하단의 **[확인]** 버튼을 눌러 설정을 저장하고 인터넷 접속 여부를 테스트합니다.

---

### Step 4. DNS Client 서비스 재시작

윈도우 시스템 내부에서 DNS 조회 요청을 담당하는 서비스(Background Service)가 멈춰있는지 점검합니다.

1. 단축키 `Win + R`을 누르고 `services.msc`를 입력한 뒤 Enter를 누릅니다.
2. 서비스 목록에서 알파벳 순서대로 내려가 **[DNS Client]** (또는 **DNS 클라이언트**) 항목을 찾습니다.
3. 해당 항목을 마우스 우클릭합니다. 
4. **[재시작]** 옵션이 활성화되어 있다면 **[재시작]**을 클릭합니다. (만약 버튼이 비활성화되어 회색으로 보인다면 Step 1의 명령어 작업이 해당 역할을 대신했으므로 다음 단계로 넘어갑니다.)

---

### Step 5. 네트워크 어댑터 드라이버 삭제 및 재설치

랜카드 드라이버 파일이 손상되었을 때 발생하는 근본적인 문제를 해결하는 방법입니다.

1. 단축키 `Win + X`를 누른 후 메뉴에서 **[장치 관리자]**를 선택합니다.
2. **[네트워크 어댑터]** 항목의 왼쪽 화살표를 눌러 메뉴를 펼칩니다.
3. Realtek, Intel, Qualcomm 등의 이름이 포함된 본인의 랜카드/Wi-Fi 장치를 마우스 우클릭합니다.

[캡처 화면 설명: 장치 관리자 트리 구조에서 네트워크 어댑터 하위의 Realtek PCIe GbE Family Controller 장치를 우클릭하여 '디바이스 제거' 메뉴가 나온 화면]

4. **[디바이스 제거]**를 클릭합니다. (※ 경고 창이 뜰 때 '이 장치의 드라이버를 제거합니다' 체크박스가 있다면 **체크하지 않고** 제거 버튼을 누릅니다.)
5. 장치가 삭제되면 상단 메뉴바의 **[동작] -> [하드웨어 변경 사항 검색]**을 클릭합니다.
6. 윈도우가 랜카드를 자동으로 다시 인식하고 깨끗한 기본 드라이버를 재설치합니다.

## 3단계: 추천 DNS 서버 비교 및 실무 팁

DNS 주소를 기본값(자동 할당)으로 두는 것보다 고성능 공용 DNS를 설정해 두면 인터넷 웹서핑 속도와 보안성이 향상됩니다. 상황에 맞게 선택하여 설정하세요.

### 주요 추천 DNS 서버 비교표

| 추천 서비스명 | 기본 DNS (주) | 보조 DNS (부) | 특징 및 최적의 사용 상황 |
| :--- | :--- | :--- | :--- |
| **Google Public DNS** | `8.8.8.8` | `8.8.4.4` | **[강력 추천]** 글로벌 접속 안정성 최고, 오류 해결 시 1순위 선택 |
| **Cloudflare DNS** | `1.1.1.1` | `1.0.0.1` | 업계 최속의 반응 속도(Latancy), 개인정보 보호 강화 |
| **KT 올레 DNS** | `168.126.63.1` | `168.126.63.2` | 국내 웹사이트 접속 시 가장 빠른 반응 속도 보장 |
| **Quad9 DNS** | `9.9.9.9` | `149.112.112.112` | 악성코드 및 피싱 사이트 차단 기능 기본 탑재 (보안 특화) |

> **💡 실무 꿀팁:** 
> 해외 직구 사이트나 해외 서버 게임(Steam, EA 등)을 자주 이용하신다면 **Google** 또는 **Cloudflare DNS**로 변경해 두는 것이 패킷 손실(Packet Loss)을 줄이고 접속 끊김 현상을 예방하는 데 큰 도움이 됩니다.

## 4단계: 자주 발생하는 오류 및 트러블슈팅 FAQ

### Q1. 스마트폰 Wi-Fi는 잘 되는데, PC만 'DNS 서버가 응답하지 않습니다'라고 뜹니다. 원인이 무엇인가요?
**A.** 모뎀과 공유기는 정상이지만 PC 내부의 네트워크 설정(DNS 캐시, 랜카드 드라이버, 방화벽)이 오염된 상태입니다. 본문 **2단계의 Step 1(DNS 캐시 초기화)**과 **Step 2(구글 DNS 설정)**를 적용하시면 90% 이상 즉시 해결됩니다.

### Q2. 구글 DNS(8.8.8.8)로 변경했는데도 여전히 인터넷이 안 됩니다.
**A.** 사용 중인 타사 백신(AhnLab V3, 알약, Kaspersky, Avast 등)의 **'실시간 네트워크 감시'** 또는 **'웹 보호'** 기능이 네트워크 통로를 블로킹하고 있을 가능성이 높습니다. 백신 감시 기능을 잠시 종료하거나, Windows Defender만 남기고 타사 보안 프로그램을 삭제한 후 재부팅해 보세요.

### Q3. DNS 주소를 8.8.8.8로 수동 변경하면 보안상 위험하거나 요금이 발생하나요?
**A.** 전혀 그렇지 않습니다. Google Public DNS 및 Cloudflare DNS는 전 세계 수억 명의 사용자가 이용하는 완전히 무료이고 안전한 공용 서비스입니다. 통신사 기본 DNS보다 오히려 보안성이 높고 개인정보를 수집하지 않으므로 안심하고 사용하셔도 됩니다.

## 요약 및 마무리

"DNS 서버가 응답하지 않습니다" 오류는 대부분 윈도우 내부의 임시 주소 정보 꼬임이나 통신사 DNS의 일시적 문제로 발생합니다.

1. `cmd`를 통한 **DNS 캐시 초기화(`ipconfig /flushdns`)**
2. 네트워크 속성에서 **구글 DNS(`8.8.8.8`)로 수동 설정**
3. **IPv6 프로토콜 비활성화**

위 3가지 핵심 조치만으로도 대부분의 네트워크 장애는 깔끔하게 해결할 수 있습니다. 

만약 안내된 모든 단계를 차례대로 적용해 보았음에도 해결되지 않는 경우, 또는 특정 단계에서 막히거나 다른 형태의 오류 코드가 출력된다면 **댓글로 현재 상태(윈도우 버전, 이용 중인 통신사)를 남겨주세요.** 확인하는 대로 추가 해결책을 친절히 안내해 드리겠습니다!
